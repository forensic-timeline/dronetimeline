Welcome to DroneTimeline's documentation!
==========================================

DroneTimeline is a plugin-based forensic timeline analysis tool. It allows investigators
to import, merge, and analyze digital forensic timelines from drone and other digital devices.
The application features a modular plugin architecture using pluggy, where each feature
(File menu, Timeline menu, Entity Recognition, Saved Timeline) is a separate installable plugin.
